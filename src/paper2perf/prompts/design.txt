referencing that fact instead of silently aggregating.

scenario, not a source_scope blocker. A per-clock rate without a clock stays unresolved.

Design repair contract:

  as a typed blocker; record adapter-unmodeled details as limitations. Never silently discard it.
- Do not require register-file bandwidth, L2/DRAM fixed latency, SM waves, or a source-provided
  GEMM schedule. These are absent from the adapter's input contract; hw-perf constructs a schedule.

  the adapter does not separately simulate accumulator-type timing. State that limitation.
- For a combined L1/SMEM node, select combined capacity, not maximum configurable SMEM capacity.
  Preserve per-SM units and reference the product SM count. A configurable split is not required

  applicability of the selected capacity fact.
- If hbm-proxy is explicitly active, a missing local-memory/shared-memory bandwidth is a recorded

- If a prior blueprint is supplied, preserve its valid source references and change only the
  demonstrated defect. Compiler-generated proxy assumptions are not source references; replace them

  selected-variant memory levels, evidence checks, and precision constraints.

Resource identity and containment:
- A link's endpoints must match its cited relationship's resource IDs. Do not mix a container ID
  into links with an invented compute alias, or rename only one side of a resource reference.
  A memory-to-memory link must cite a documented connects relationship. Never cite a contains
  relationship as a projected memory link; if no connects relationship exists, omit the link
  and report the missing path for retrieval.
- When a grouping container is not a hardware node, the compiler may project its connections onto
  its uniquely documented contained modeled memory boundary. This is an explicit aggregate-model
  abstraction, never an equivalence between different compute resources. resource_bindings records
  source_resource, memory_resource and the proving containment_id. Ambiguous boundaries require
  an explicit evidence-backed selection or a typed blocker; never a fuzzy name match.
- The compiler restores omitted selected-variant connects relationships and validates all endpoints.
  Preserve bandwidth references when known; recovered links need evidence or the explicit proxy policy.
  Do not add a topology blocker merely because your selected links omit a documented connects
  relationship; the compiler restores it and projects logical pool views. Block only when the
  source relationship itself is absent or its boundary is ambiguous.
- contains relationships between grouping/memory nodes are not additional physical bandwidth links.
  Use containment_access only for a modeled compute parent's local-memory child. Retain grouping
  containment in the evidence or resource binding, not as a fabricated memory-access channel.
  If no contains relationship has the modeled compute as source and its local memory as target,
  omit containment_access rather than reusing a grouping container's contains relationship.

Source-conflict contract:
- source_conflict is only an unresolved contradiction between at least two extracted numeric facts
  about the SAME quantity, selected variant, precision/mode, aggregation and units. Supply both IDs
  in conflicting_fact_ids. A single reference_id plus a narrative is insufficient.
- A full-die configuration and a shipping product configuration are different scopes, not conflicting
  counts. Select the requested variant from its cited facts; retain the excluded comparison in limitations.
- Likewise, sparse versus dense and per-core versus device rates are different scopes. Do not call
  a comparison unresolved after your own reasoning has already selected the applicable facts.
- PDF raised digits are retained as superscripts where layout permits. A superscript footnote attached
  to a table value is not another baseline digit. Prefer an unambiguous prose passage if table geometry
  is unclear. Never label a table a typo just because a plain-text representation joined annotations.
- If applicability truly cannot be resolved, retain source_scope or a supported paired source_conflict
  blocker. Never remove a genuine uncertainty merely to complete the experiment.

A resource_bindings source_resource MUST NOT appear in memories or computes. If an SM is already

Shared physical blocks and newly retrieved evidence:
- A shares_resource relationship denotes logical views of one physical memory, not a bandwidth link.
  Use the combined-capacity fact once for that pool. Do not allocate the same combined capacity to
  both views, and do not omit one view without a proved physical-pool representation.
- Do not add a resource_binding for a member of a proven memory_pools entry; the pool already
  aliases it. A resource_binding is only for an unmodeled grouping container.
- A connects relationship between two logical views of one proven pool is internal to the pool;
  do not also emit it as a bandwidth link.
- memory_pools can identify memory_id, member_resource_ids, proving relationship_ids, and the
  selected combined capacity_fact_id. The compiler also recognizes a unique pool from an explicit
  single-memory-block quote and that combined-capacity reference. It records both logical identities
  and never guesses a sharing relationship from similar names.
- The compiler may restore source connects edges but cannot invent an absent SM/cache path. Missing
  physical capacities or source connectivity require targeted retrieval, not an explanatory limitation.
- When new verified facts arrive, re-evaluate the previous plan: use a newly supplied device-memory
  capacity fact rather than keeping a stale null reference or an old 'not corroborated' limitation.
  Likewise, add newly supported connectivity. Only unresolved applicability belongs in blockers.
The backend requires memory-only intermediate hops. Every modeled memory must have a documented
memory-to-memory path from external memory. A connected graph whose only path to local memory
passes through a compute node is incomplete. Retain extracted cache/global-to-shared transfer
relationships as memory connections; don't replace them with edges to an actor and call the graph
routable. The compiler reports missing source memory paths for targeted retrieval.

Already-combined memory:
- A single modeled combined L1/SMEM resource is an ordinary memory node with one combined-capacity
  reference. Do not create a memory_pools entry with one member, repeat its ID to fake two members,

- A reflexive shares_resource annotation on an already-combined source resource is not a transfer

  capacity. Genuine self-transfers are not automatically treated as physical sharing.
